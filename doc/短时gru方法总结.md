# 论文信息提取：基于短时 GRU 关联网络的路侧雷达多扩展目标跟踪算法[cite: 1]

## 1. 基本信息
*   **文章标题**：基于短时 GRU 关联网络的路侧雷达多扩展目标跟踪算法[cite: 1]
*   **文章摘要**：针对交通场景中路侧毫米波雷达扩展目标多点散射、目标密集交互以及杂波与漏检并存条件下的跟踪问题,本文提出一种基于短时门控循环单元(Gated Recurrent Unit, GRU)数据关联网络的路侧雷达多扩展目标跟踪算法[cite: 1]。该方法将量测与航迹状态统一映射至共同状态空间,构造当前量测与候选航迹短历史状态之间的残差序列,并利用GRU提取短时动态一致性特征;同时引入虚拟目标类别和有效掩码机制,实现杂波判别、动态量测与航迹条件下的多量测归属及连续跟踪[cite: 1]。仿真结果表明,所提算法在不同检测概率及综合复杂交通场景下均获得较小的OSPA距离、较高的F1值和较低的关联耗时,具有较好的关联精度、鲁棒性与实时性[cite: 1]。

## 2. 网络结构与输入输出维度 (I/O Shapes)
实验具体参数设定：单帧最大量测数 $M_{max} = 200$，单帧最大航迹数 $N_{max} = 64$（加1个虚拟目标共65类），历史序列长度 $H = 4$，状态特征维度 $D = 4$[cite: 11]。

*   **整体输入层 (残差序列张量)**
    *   **输入内容**：所有对齐后的量测点与所有候选航迹短历史状态相减得到的残差序列[cite: 7, 8]。
    *   **Shape**：`[200, 65, 4, 4]` (即 `[M_max, N_max+1, H, D]`)[cite: 11]。
*   **GRU 时序特征提取层**
    *   **输入 Shape**：`[4, 4]` (即单对量测-航迹组合的 `[H, D]` 序列)[cite: 7, 8]。
    *   **输出 Shape**：`[64]` (提取最后时刻的隐状态作为特征向量)[cite: 9, 11]。
*   **MLP (多层感知机) 打分层**
    *   **输入 Shape**：`[64]`[cite: 9, 11]。
    *   **输出 Shape**：`[1]` (输出当前量测与候选目标的匹配标量得分)[cite: 9, 11]。
*   **Softmax 概率归一化层**
    *   **输入 Shape**：`[65]` (单一量测点针对所有候选类别的得分向量)[cite: 9]。
    *   **输出 Shape**：`[65]` (归一化后的分类概率分布)[cite: 9]。
*   **整体输出层 (关联矩阵)**
    *   **输出内容**：整个场景下所有量测点对各航迹的归属判定（基于最大概率决策）[cite: 10]。
    *   **Shape**：`[65, 200]` (即 `[N_max+1, M_max]` 的关联矩阵)[cite: 4, 11]。
*   **损失函数 (Loss)**
    *   **采用方法**：加权 Mask 交叉熵损失 (Weighted Mask Cross-Entropy Loss)[cite: 10]。通过 Mask 屏蔽补零的无效量测，通过权重系数 $\lambda$ 增强对杂波（虚拟目标类别）的识别惩罚[cite: 10]。
