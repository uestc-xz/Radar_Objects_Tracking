# 独立短窗候选排序 Implementation Plan

> 按 spec-coder 逐项在当前工作区实施；用户已授权自行细化与执行，提交由用户手动完成。

**Goal:** 先检验“给定量测历史，在真实竞争候选中选择同槽候选或拒绝”的学习能力。

**Architecture:** 只读冻结 M1 的 out/conf，原主/弱聚类生成当前提议。GT 仅在离线构造历史和排序标签时使用；模型接收相对量测，不接收 GT 坐标和 ID。此阶段使用条件正确历史，刻意拆开排序能力与闭环错误累积，结果不能声称是跟踪身份收益。

**Tech Stack:** 项目现有 NumPy、PyTorch、SciPy、tqdm、unittest。

**Spec:** `SPEC.md` 实验模块 29。

## 冻结条件与输入输出

- 坐标米制；标签十行均值为 `[3,2]`，空槽零，不重复 y 偏移。
- 每文件夹独立；用 sample_id 差表示年龄，禁止未来信息和跨序列历史。H=现有 HIST_LEN=20。
- 沿用 LifecycleTracker 的 .96 主提议、.8 弱提议及 .75m 聚类/主弱去重，所有提议保留，不限为前三个。
- 离线每帧用 .5m gated_pairs 对提议与有效 GT 一对一配对。历史仅保存配对量测 xy/score/sample_id；不保存 GT 坐标为输入。每个槽至少两次过去观测才有查询，启动帧没有查询不等同已被检测。
- 当前帧目标为同 GT 槽配对的提议下标+1，未匹配为 0(null)；先构造查询，再插入当前量测。GT 槽只用于离线分组，不进入网络张量。
- 历史 `[B,H,5]`：相对最后观测的 dx/dy（米）、score、年龄/H、valid。按实际时间格子从旧到新摆放，缺帧置零。当前 `[B,N,4]`：相对最后观测 dx/dy、score、is_primary，另有 `[B,N]` padding mask。
- 历史 MLP `5H→64→32`；共享边 MLP `(32+4)→64→1`；null MLP 用历史编码和候选数/最小距离/最高分，`35→32→1`。softmax 本身在当前候选之间竞争。边/null 末层均零初始化。
- 基础 logits：候选 `-distance/.25`，null `-1/.25`，学习头加残差；此 .25 是固定米制 logit 温度，不是 gate 或可学习标签尺度。没有人为坐标回归任务。

## 损失与诊断

`L = mean_q(-log softmax([null, valid candidate logits])[label_q])`。平均的是每个查询的标量损失，不是把不同目标坐标平均。padding 为极小有限 logit；无候选时只有 null，损失 0，梯度有限。没有 CLUTTER_WEIGHT 或其他旧损失权重参与。

手算：一个候选和 null 的 logits 都为 0，任意正确类损失为 log(2)；两个候选及 null 都为 0 则 log(3)。错误 padding 不能进入分母或 argmax。

与最近观测、最近两次观测的限速 .2m/sample 直线预测基线用完全相同的查询/提议/1m 拒绝门比较。速度基线是诊断，不冒充原 tracker 的 EMA/衰减实现。

分母必须可见：所有查询、positive、null、positive 且最后观测 1m 内至少两个候选（competition）、几何歧义 positive、非歧义 positive，并按序列报告。歧义定义为当前正候选离另一个有效 GT 的距离不比所配 GT 远 .15m，或另一个当前提议到该 GT 的距离不比正候选远 .15m（含一对一强制非最近的情况）；不删除歧义样本，不宣称几何标签是真实身份。

补充区分：`ranking_accuracy` 在 positive 查询上暂时排除 null，只比较候选 logits 的 argmax；它不表示可以在推理时知道正样本。并列 `wrong_candidate / false_reject / false_accept`，防止把更多拒绝导致的选错减少误读为身份排序改善。

历史通过几何配对挑选，包含过去配对歧义，不能称为真实纯净身份历史；查询独立排序，尚不约束两个历史选择同一候选。主弱候选一起竞争也不同于原 cascade 管理器。因此本实验的最近点准确率不是旧 tracker 的身份指标，不能拿它替换完整跟踪回放。

结论：网络可训练，条件训练/验证尺度接近，但收益主要来自 null 判断，竞争选择含拒绝的表现全部序列退化。排除 null 的竞争排序仅净多选对一个，不足以证明可泛化身份能力；不接入默认 tracker，不宣称系统 IDF1 改善。

此外，标签 .5m 与基线拒绝门 1m 本来不同；本轮未证明网络优于训练集标定的简单拒绝阈值，所以总体准确率增益也不能归因于学到了历史身份信息。数据和历史仍以几何代理配对定义，有歧义/选择偏差；验证集已被多次探索，不是独立测试集。

下一轮候选方向：保持数据/标签/候选与现有实验冻结，拆分“在正候选里选谁”的条件排序 CE 和“当前是否存在可接候选”的可匹配性监督；单列竞争样本的学习贡献，避免 97.93% 非竞争查询主导。先检查分项梯度和竞争正确率，不能只追总体 CE；效果仍须实测，暂未实现该后续方向。
