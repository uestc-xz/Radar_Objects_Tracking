# 关联跟踪方案任务书

> 目标：在 `original/`（已发表定位基线）之上，将其拓展为「目标关联的跟踪」，
> 复现/适配论文《基于短时 GRU 关联网络的路侧雷达多扩展目标跟踪算法》
> （`doc/短时gru方法总结.md`）。本文档是后续编程的**唯一蓝图**，每个子模块单独检视。

---

## 0. 背景与动机

- 现状：`original/` 是**端到端定位**（DETR，50 个 query 直接回归 3 人中心），
  定位本身有误差，且无跨帧身份概念。
- 论文：定位基于**传感器已获得的量测**，跟踪阶段用 GRU 关联网络把「量测」与「航迹短历史」做残差匹配。
- 我们的适配思路：DETR 的 50 个 query 输出天然充当「量测」，3 个航迹槽充当「航迹」；
  额外从 `dec_output`（当前被丢弃的 `[50,128]` 特征）接出一条特征分支，补充论文所没有的高维身份信息。
- 形态：**tracking-by-detection**（先定位出目标，再做帧间 ID 关联），非联合检测跟踪。

---

## 1. 口径统一（论文参数 → 我们参数）

| 符号 | 含义 | 论文值 | 我们取值 |
|---|---|---|---|
| `M` | 单帧最大量测数 | 200 | **50**（DETR query 数） |
| `N` | 最大航迹数 | 64 | **3**（最多人数） |
| 类别数 | 航迹 + 1 虚拟杂波 | 65 | **4**（3 航迹 + 1 杂波） |
| `H` | 历史序列长度 | 4 | **待实验定**（2 / 4 / 8，见 D2） |
| `D` | 状态特征维度 | 4 | **4** = `(x, y, vx, vy)` |
| 量测特征 | 论文无高维特征 | 仅几何 | **128 维** `dec_output`（我们的增益点） |

关键物理量：**帧间隔 `Δt = 0.24s`**（10 个雷达慢时间周期 = 1 帧）。
速度由相邻帧中心差除以 `Δt` 得到。

## 2. 总体数据流

```
雷达帧 x_t ∈ ℂ^{8×89×10}                       (batch=1)
  │
  ▼ M1 定位前端（复用 Mymodule，仅改返回值）
  coor [50,2]    conf [50,2]    feat [50,128]
  │                │                │
  │                │                ▼ M4 特征映射 φ(·)
  │                │              φ(f) [50,128]
  │                │                │
  │                │                ▼
  │                └─────────►  M2 量测生成  m_i = (p_i, s_i, f_i)
  │                                       i = 1..50
  ▼
  M5 几何残差 GRU（量测 × 航迹短历史）──► g_geom [64]
  M6 融合打分 ──► S [50,4]（0=杂波，1..3=航迹）
  ▼
  M7 关联决策（softmax over 4 类 + 1对1 约束）──► k_i ∈ {0,1,2,3}
  ▼
  M8 航迹更新 ──► M3 航迹状态库 T = {T_1, T_2, T_3}
```

## 3. 模块详设

### M1 定位前端（改 `original/123ren.py` 的 `Mymodule.forward`）

| 输出 | 符号 | shape | 含义 |
|---|---|---|---|
| 中心坐标 | `coor` | `[50,2]` | 50 个 query 回归的 `(x,y)`，即现有 `out[:, :2]` |
| 置信度 logits | `conf` | `[50,2]` | `conf_head` 两分类 logits（`[0]`背景 / `[1]`有目标） |
| 特征 | `feat` | `[50,128]` | `Decoder.forward` 第 4 个返回值 `dec_output`，**当前被丢弃** |

改动唯一处：`coor_pred, wh_pred, conf, _ = self.DETR_Decoder(...)` 的 `_` → `feat`，随 `coor/conf` 一起返回。

> 备注：现有 `out[:, 2:]` 实为 `classifier` 头的两分类 logits（与 `conf` 冗余、损失未用），
> **不是真正的 w/h**。跟踪只用 `coor + conf + feat`，不用它。

### M2 量测生成（新）

- **输入**：M1 的 `coor [50,2]`、`conf [50,2]`、`feat [50,128]`。
- **输出**：量测集合 `M = { m_i }`，`i = 1..50`，每个量测为三元组

  ```
  m_i = ( p_i ,  s_i ,  f_i )
         p_i = (x_i, y_i) ∈ R²         中心坐标，= coor[i]
         s_i ∈ [0,1]                   目标置信度，s_i = softmax(conf[i])[1]
         f_i ∈ R¹²⁸                    128 维特征，= feat[i] = dec_output[i]
  ```

- 批量张量表示：`P [50,2]`、`S [50]`、`F [50,128]`。
- **职责区分**：`s_i` = 「是不是真实目标」（DETR 自己的置信度，供 M7 门控/杂波判别）；
  `f_i` = 「是哪个目标」（身份特征，供 M6 跨帧匹配）。

### M3 航迹状态库（新，核心）

航迹集合 `T = { T_k }`，`k ∈ {1,2,3}`（固定 3 槽）。每条 `T_k`：

| 字段 | shape | 含义 |
|---|---|---|
| `x_k, y_k` | 标量 | 滤波后的目标中心 |
| `vx_k, vy_k` | 标量 | 速度，EMA 平滑，`Δp / 0.24s` |
| `f_k` | `[128]` | 身份特征，EMA：`f_k ← (1−α)f_k + α·φ(f_i)` |
| `hist_k` | `[H,4]` | 最近 H 帧的 `(x,y,vx,vy)`，不足 H 帧用首帧复制补齐 |
| `age_k` | 标量 | 出生后帧数 |
| `miss_k` | 标量 | 连续未匹配帧数 |
| `alive_k` | `{0,1}` | 槽位是否存活（空槽 = 0，等价 GT 的 `(0,0)`） |

> 说明：我们数据集**每条序列人数固定**（`SPEC.md` §1），因此跟踪任务 = **纯 ID 维持**
> （每帧检测属于哪个人），出生/死亡仅在序列边界发生，帧内只做匹配 + coast。

### M4 特征映射分支（新）

| 项 | 值 |
|---|---|
| 输入 | `feat [50,128]` |
| 映射 | `φ(·)`：`Linear(128→128)` + `LayerNorm`（`dφ` 可消融为 64） |
| 输出 | `φ(f) [50,128]` |
| 作用 | 把「定位特征」映射到「关联/身份特征空间」，与 M5 解耦，独立消融点 |

### M5 几何残差 GRU（借论文）

| 项 | 值 |
|---|---|
| 输入 | 量测 `p_i=(x_i,y_i)` + 航迹 `hist_k [H,4]` |
| 残差构造 | 对每个历史步 h：`r_h = (x_i − x_k^{(h)}, y_i − y_k^{(h)}, 0 − vx_k^{(h)}, 0 − vy_k^{(h)})`（量测无速度，速度通道只来自航迹侧） |
| 输出 | 残差序列 `[H,4]` → `GRU(hidden=64)` → 最后隐状态 `g_geom ∈ R⁶⁴` |

### M6 融合打分（新）

| 项 | 值 |
|---|---|
| 输入 | `g_geom [64]`（M5）、`φ(f_i)`、`φ(f_k)`（M4） |
| 特征相似度 | `sim(i,k) = cos(φ(f_i), φ(f_k)) ∈ R` |
| 方案 A（晚融合，默认） | `concat([g_geom, sim]) ∈ R⁶⁵` → `MLP` → 标量 `S[i,k]` |
| 方案 B（早融合，待消融） | `φ(f)` 直接并入 GRU 输入通道（另定义，暂不做） |
| 输出 | `S [50,4]`（第 0 列 = 杂波分） |

### M7 关联决策（借论文 + 我们约束）

打分矩阵 `S [50,4]`：第 0 列 = 杂波分，第 1..3 列 = 与 `T_1..T_3` 的匹配分。

逐帧流程：

1. **门控（可选）**：`I = { i : s_i ≥ τ }`；不做门控则 `I = 全部 50`。（→ 决策 D4b）
2. **逐量测 softmax 分类（论文原版）**：对每个 `i ∈ I`，`p_i = softmax(S[i,:]) ∈ R⁴`，取 `k_i = argmax p_i`。
3. **1 对 1 约束（我们加）**：若多个 `i` 使 `k_i = k(≥1)` 相同，只保留 `p_i[k]` 最大者，其余改判 `k_i = 0`（杂波）。—— tracking-by-detection 不许多量测→同航迹。
4. **判定**：`k_i = 0` → 杂波/背景丢弃；`k_i = k ≥ 1` → 量测 i 归属航迹 `T_k`。
5. **航迹侧**：`matched_k = { i : k_i = k }`（空或 1 元素）：
   - 非空 → 用该量测更新 `T_k`（M8）；
   - 空 → `miss_k += 1`，位置按 `(vx,vy)` 外推（coast）。
6. **生命周期（兜底）**：`miss_k ≥ L` → 判死释放槽位；高 `s_i` 且未匹配量测 + 有空槽 → 新生。

**损失**：加权 mask CE —— 补零/空槽位置加 mask 不计损失；杂波类乘权重 `λ > 1` 增强惩罚。
监督信号 = GT 固定槽位伪 ID 经匈牙利匹配得到的「量测 → 航迹」真值（见 §5 任务 7）。

### M8 航迹更新（新）

| 项 | 值 |
|---|---|
| 输入 | `k_i` 归属 + 量测 `m_i` |
| 位置 | `(x_k,y_k) ← EMA(匹配量测 p_i)` |
| 速度 | `(vx_k,vy_k) ← EMA(Δp / 0.24s)` |
| 特征 | `f_k ← (1−α)f_k + α·φ(f_i)` |
| 历史 | `hist_k` 追加 `(x_k,y_k,vx_k,vy_k)`，截断保留最近 H 帧 |
| 未匹配 | coast（外推），`miss_k += 1` |

## 6. 评估指标

- **逐帧关联正确率**：匹配对中 ID 正确比例（序列内 GT 伪 ID 为真值）。
- **ID switch 次数**：序列内身份跳变次数，越少越好。
- **MOTA / MOTP**（若引入漏检/误检口径）。
- **定位误差回退对比**：加跟踪前后 `coor` 的中心误差，验证跟踪不损害定位。
- **关联耗时**：与论文口径一致（单帧推理 ms）。

### 9.1 当前版本充分训练后实际学到什么

训练目标唯一一条：`加权CE(S, labels)`，其中 `labels = build_assignment_targets(...)`，
而 `build_assignment_targets` 是一段**手写启发式规则**：

1. `s_i ≥ τ(=0.96)` 的量测 = 候选，其余 → 杂波（类 0）；
2. 候选与有效 GT 槽位做**欧氏距离匈牙利**匹配 → 赋槽位类（1/2/3）；
3. 多余的候选 → 赋最近 GT 槽位的类。

因此充分训练后，网络收敛到**复现这条规则**——即「对每个量测，预测①它是不是置信度低于 τ 的杂波；
②若是目标，离哪个 GT 槽位最近」，而非「学会跟踪」。

### 9.2 已确认的问题清单

#### A. 目标函数 / 监督信号层（根因所在）

| # | 问题 | 影响 |
|---|---|---|
| 1 | M1 之后无任何位置回归损失；航迹位置 = M1 量测的 EMA | 无法纠正 M1 定位误差，量测偏则航迹偏 |
| 2 | 身份特征 φ(f) 从未被监督做跨帧身份（labels 只用位置+置信度） | 身份分支形同虚设（§8 D1 风险已兑现） |
| 3 | labels 用硬阈值 τ=0.96 划杂波，但网络输入不含 s_i | 目标与输入存在信息缺口；硬阈值损失多种可能 |
| 4 | 雷达遮挡 → M1 漏检（高置信度量测 < 真人数）时，被漏目标的槽位类不进入 labels | GT 标签始终完整（空槽仅=序列人数<3，非遮挡），但被漏目标无人可匹配 → 无可学内容，仅硬编码 coast |
| 5 | labels 每帧独立生成，无任何跨帧/时间监督项 | GRU 历史读了但无独立价值 |
| 6 | ~~「类 j = 身份 j」依赖 GT 槽位顺序跨帧稳定~~ | ✅ 已确认不成立：文件夹内槽位顺序固定（作者确认 + 数据抽查），关闭 |

#### B. 结构 / 状态机层

| # | 问题 | 影响 |
|---|---|---|
| 7 | 量测间无通信（M4 逐点 Linear，无 attention） | 无全局视野，每量测独立分类 |
| 8 | 航迹间无通信（互斥仅在推理 associate 硬做） | 无显式协调（是否必要，待讨论） |
| 9 | 训练(τ 阈值) 与 推理(不门控) 的杂波口径不一致 | 训练教一套、推理用另一套 |
| 10 | 出生/死亡缺失，alive 门控未实现 | 3 航迹永远存活，人数 <3 时多余航迹永久 coast |
| 11 | f_i 是定位特征，非身份特征 | 特征相似度可能不含身份信号 |
| 12 | 自回归无 teacher forcing（exposure bias） | 训练不稳（暂缓处理） |

**数据核实（2026-10-20）**：抽查测试集两个文件夹——`20240913_1_1`（1245 帧，恒 1 人）、
`20240916_2_3`（2494 帧，恒 2 人，其中 58 帧雷达遮挡）。两文件夹内 GT 槽位集合跨帧恒定
（槽位顺序固定 → A-6 关闭）；且**遮挡帧的 GT 槽位仍填满真实坐标**——遮挡只发生在雷达信号侧，
标签侧无遮挡。故 A-4 的真实场景 = 「雷达遮挡 → M1 漏检，但 GT 完整」。

### 9.3 作者最新意见（方向性）

- **置信度 s_i 是好参考，但不可硬编码阈值**：保留为软信号，而非 τ 一刀切（对应 A-3）。
- **通信优先补两处**（直观、易实现）：
  1. 量测 ↔ 量测通信（50 个量测相互 attention）；
  2. 历史 ↔ 当前帧通信（航迹历史与当前量测的时序 attention）。
  航迹 ↔ 航迹通信较复杂，**暂缓**。
- **航迹状态机必须完善**（对应 B-10）：出生/死亡/存活要有完整模块描述，当前实现过于简单。

### 9.4 待深度讨论（定稿前须拍板）

- 身份标签是否**跨帧生成**（而非每帧独立位置最近邻）？
