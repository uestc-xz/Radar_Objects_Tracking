# 冻结 M1 单帧集合纠偏实验

状态：旧集合模型运行 12 轮后由用户中止；量测锚定残差已完成两轮，正在验证点簇显式证据对照。

## 目的与边界

验证冻结 M1 的候选坐标和前景置信度，能否通过轻量学习模块形成更准确的逐帧目标点。此实验不输入 M1 的 128 维特征、不读取历史状态、不预测 ID；输出槽是无序集合，不可解释为固定身份。

不修改现有 `train.py`、`train_tracker.py`、`JointTracker`、`TrackBank`、配置默认值或既有 checkpoint。M1 输出来自冷缓存，不加载或训练 M1。

## 数据接口

- 每个样本为独立帧，输入候选坐标 `out[:, :2]`，shape `[50,2]`、米制；候选分数由缓存 `conf[50,2]` logits 的 softmax 前景概率得到。
- 标签为原始 `(10,6)` 沿样本内 10 个 chirp 时间步平均并 reshape 为 `[3,2]`；`(0,0)` 表示空 GT 槽。未添加 y 偏移。
- 训练集随机打乱帧；不同记录不拼接成时间轴。缓存路径由 `TrackSequenceColdDataset` 的 full-sequence 索引取得。
- 128 维 `feat` 保存在缓存中，但此模型明确不读取它。

## 模型与损失

候选的 `(x,y,score)` 逐点映射为 token，经无位置编码的 Transformer 集合编码；三个可学习 query 通过 cross-attention 汇总候选集合，输出三组米制坐标和存在 logits。无候选筛除，score 作为软输入。集合编码对候选排列不变。

对每个样本，用预测坐标与有效 GT 坐标的欧氏距离做 Hungarian 最小代价匹配；GT 槽顺序不参与监督。匹配点用 Smooth-L1（默认 beta=1）监督坐标，匹配预测的存在标签为 1、其余输出槽为 0。存在 BCE 对 batch 的全部输出槽求均值；位置项对 batch 内匹配点的 x/y 元素求均值；总损失 `L = L_position + 0.5 * L_presence`。全空帧的位置损失为可反传的零，存在项仍训练所有输出为 absent。

训练每轮验证以存在概率 `>=0.5` 选输出点，使用 1m 评估门限逐帧匈牙利匹配，报告 P/R/F1/匹配 MAE。与 M1 baseline 对比时必须使用相同验证记录、TP 门限，并同时看召回和预测数量；匹配 MAE 只统计 TP，不可单独解读。

## 当前验证与限制

- CPU 单元测试覆盖输出 shape/有限性、输入候选置换不变、GT 槽置换损失不变、空帧损失与反传、冷缓存路径/logit softmax/标签均值。
- 真实验证缓存检查：8 条记录、17,421 帧；样本缓存形状为 `out=(50,4)`、`conf=(50,2)`、`feat=(50,128)`，标签 `(3,2)`，抽样 logits 有限。
- 该模块没有跨帧身份信息；即便单帧点位指标优于 baseline，也不表示 ID 连续性改善。
- 当前用验证集选择 best epoch，验证集指标只作实验筛选；正式泛化结论需后续独立留出数据或冻结 epoch 后评估。

## 2026-10-23：量测锚定残差对照（实施方案）

### 证据与假设

旧模型 12 轮中最佳逐轮 F1 为第 5 轮 0.8616；按验证总损失保存的是第 6 轮，阈值 0.5 时 F1=0.8201、匹配 MAE=0.3359m。保持该检查点坐标不变扫描存在阈值，约 0.35 可恢复 F1 至 0.856，仍低于无学习聚类基线的 0.8942/0.2778m。因此不能只归因于训练不足或阈值；旧模型从 learned query 重建绝对坐标、没有 M1 坐标直连，是本轮要验证的结构假设，并非已经证实的唯一原因。

### 冻结边界与接口

保留旧 `SingleFrameSetPredictor` 和 `--model set` 默认行为，不触碰原 tracker。新增 `--model cluster-residual`，仍输入冻结 M1 的 `[B,50,2]` 坐标和 `[B,50]` score；输出最多三个无序点及 logits，另带仅用于损失的原始锚点和 proposal mask。旧 checkpoint 无模型类型字段时按 `set` 加载；新 checkpoint 保存类型和实验参数。

### 预测与监督

1. 先对 score>=0.96 的量测按 0.75m 连通聚类，按 score 加权得到主锚点；再对 score>=0.8 聚类，加入距离所有主锚点均大于 0.75m 的补充候选。锚点按分数降序、坐标打破并列，保留前三个，不使用 GT 决定 proposal。缺槽为 masked padding。
2. 每个锚点只汇总 1m 邻域量测的相对坐标/score，经小 MLP 提取证据；保留原始锚点坐标和 score。坐标=`anchor+0.5*tanh(delta)`，每轴最大纠偏 0.5m；存在 logit=`logit(anchor_score)+learned_delta`。两输出头零初始化，保证初始预测保留量测，而非随机绝对坐标。无 proposal 的 padding 永远不作为预测。
3. 训练只在有效原始锚点与 GT 距离<=1m 的配对中做最大匹配数、再最小距离的 Hungarian；匹配关系不跟随回归漂移。匹配点 Smooth-L1(beta=1)，proposal 存在 BCE，总权重仍为 `position+0.5*presence`；padding 不参与 BCE 归约。远离所有锚点的 GT 不强迫错误候选回归，仍在评估中计 FN。该模型不能凭空恢复被 proposal 筛掉的目标，此项必须记为召回上限而非隐藏样本。
4. 验证仍按同一 1m TP 定义报告全帧 TP/FP/FN、P/R/F1、匹配 MAE；learned presence 默认阈值统一为 0.5，与 proposal 的 M1 0.96/0.8 门限分开。首轮试验曾用 0.96 输出门限，保留原记录，通过独立扫描重新评估。另存验证 F1 最佳 checkpoint 和最近 checkpoint，不替换原有按 loss 保存的文件。

### 验收

测试先覆盖零初始化保留量测、局部纠偏界限、空候选/掩码、候选置换、门限匹配与有限反传，再比较未训练模型和 1--2 轮真实缓存结果。阈值/方案沿用本验证集探索，所有改善只作为下一轮方向筛选，不宣称独立测试泛化。

### 两轮实际结果与下一项对照

`cluster_residual_trial1` 使用学习率 1e-3、训练 59,525 帧/验证 17,421 帧。训练总损失 0.1550→0.1465，验证总损失 0.1770→0.1733；位置项基本维持训练 0.027/验证 0.029，下降主要来自存在 BCE。旧 learned-query 最佳逐轮 F1=0.8616；本试验 epoch 2，固定输出门限 0.5 时 F1=0.89245、匹配 MAE=0.28054m；探索门限 0.6 时 F1=0.89496、MAE=0.27804m，仅与聚类基线 0.89416/0.27779m 持平。不能声称明显超越基线。

单独锁定原始锚点/GT 的 29,452 个匹配对，不按新坐标或存在分数丢弃困难点：锚点 MAE=0.284631m，纠偏后=0.283467m，平均移动 0.013759m，55.67% 配对改善。约 1.16mm 的平均收益很小；此诊断用于区分坐标学习与筛选 TP 的影响，不等同于最终检测 MAE。原始 proposal 仍漏掉 2,880/32,332 个 GT，不能靠近邻残差凭空恢复。

`cluster-evidence` 对照保持 proposal、0.5m 残差、损失、学习率、数据、评估不变，在小 MLP 中额外输入八维可解释点簇证据：局部 score 加权相对均值 x/y、标准差 x/y、高分候选数和可用候选数占 50 个 query 的比例、局部最高分、最近有效其他点簇距离（截断归一化；孤立簇为 1）。所有证据只读取候选，不读取 GT/历史/feat。构造参数默认关闭，旧模型形状和 checkpoint 保持兼容。按相同种子独立跑两轮，先比较固定 0.5 门限，再单独报告验证门限探索；未超越则如实记录不扩大训练。

`cluster-evidence_trial1` 两轮结果：epoch 2 固定 0.5 门限 F1=0.89030、MAE=0.28154m；门限 0.6 的探索 F1 约 0.90，仍与基线处于同一水平，且不是预先冻结的工作门限。固定 29,452 对的锚点 MAE=0.28463m、纠偏后=0.28332m，平均残差=0.01579m，改善比例=54.98%。因此局部证据没有在两轮短训中显示稳定优势。proposal 与 GT 在 1m 内可配对 29,452/32,332，剩余 2,880 个 GT 无可纠正锚点。后续若继续，应先针对候选召回/聚类门限做有标注诊断，再加入时序/历史信息；继续堆叠单帧 MLP 特征目前证据不足。
