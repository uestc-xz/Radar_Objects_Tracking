# 训练集标定的卡尔曼关联预测（模块 28）

## 依据与选择

基线提交 `ef3ae9a`。模块 27 证明当前帧通常能收到近 GT 的量测，但不能据此证明身份正确。完整时间线进一步显示：片段 14 在 371–384 帧的更新稳定接近 GT1，386 后进入交叉区，后续出现反复归属变化；片段 26 在 858 帧仍接近 GT1，漏记十步后 873 帧接收了更近 GT0 的量测。最近 GT 只是离线几何证据，不直接当作真实身份标签。

困难序列 GT 相邻输入步位移的中位数/90%/99%/最大值为 `.1009/.2156/.3227/.5389m`，7,407 个槽间隔中 986 个大于旧速度上限 `.2m/步`。这不证明截断是全部问题，也不直接修改其默认值。此前的历史直线拟合、活动优先、外观、滞回和暂定弱续接均未稳定解决多人身份；本次选取不同的单一假设：测量噪声下的递归状态估计能否改善关联预测。

考虑过继续改变优先级、加入学习关联头、或使用显式状态估计。前者已有失败对照，后者引入新监督与滚动训练；先做可手算的状态估计对照，能较清楚区分运动预测瓶颈与候选身份本身不可分。

## 冻结范围与公式

独立子类只改变 `_association_predictions`。原量测聚类、高/弱阶段、1m 欧氏门、分数代价、出生、确认、删除、容量、原始位置/速度更新和最终输出公式不变；不接入旧网络训练。滤波位置只用于关联，不能将匹配 MAE 变化称为输出坐标纠偏收益。独立和相同参数的身份恢复组合均报告。

状态 `m=[x,y,vx,vy]`，单位为米和米/输入步。`F=[[I,I],[0,I]]`，`G=[[.5I],[I]]`，`Q=G diag(q) Gᵀ`。每个漏记输入步执行 `m'=Fm; P'=FPFᵀ+Q`。量测矩阵 `H=[I,0]`，`S=HP'Hᵀ+R`，`K=P'HᵀS⁻¹`，`m=m'+K(z-Hm')`，`P=(I-KH)P'(I-KH)ᵀ+KRKᵀ`。出生 `m=[z,0,0]`，`P=diag(Rxx,Ryy,Vxx,Vyy)`。状态保存于最后真实观测时刻；多阶段关联只计算预测副本，不能多次推进，漏检不写入伪观测。

仅从训练集冻结 M1 缓存/标签离线标定：R 是 score>=.96、半径 .75m 主聚类经 1m 门一对一配对后的逐轴残差二阶矩（偏差也计入，不自动减去偏移）；q 是同槽连续三个有效 GT 输入步二阶差分的二阶矩，V 是同槽连续两步位移二阶矩。不得跨序列或 sample ID 缺口计算差分。每轴方差下限 `1e-6` 是数值正定保护，非验证调参。保存样本数、训练序列、路径、形状、范围和参数来源；推理只接收冻结参数，不读取 GT。该估计受 1m 截断匹配、M1 错配及标签噪声影响，并非真实传感器噪声的无偏估计。

## 实施与验证顺序

1. 先写数值与行为测试，观察缺失实现失败，再完成独立子类及训练集标定脚本。
2. 给现有独立评估器增加两个显式 opt-in 名称与参数文件，不改变默认比较集合；缺少参数时报错，元信息写入结果。
3. 标定完整训练集，冻结参数；先回放困难序列 2,470 帧，再完整八序列 17,421 帧四组对照。并列 1m/.5m 检测、MAE、GT-IDSW、预测 ID 换 GT、身份 F1、假输出/片段管理，逐序列展示。
4. 校验旧两组的全部预测 SHA-256 与既有结果相同，恢复前后坐标/分数/观测标志完全相同。全套回归、静态编译、diff 检查通过后更新 SPEC/CODE_LOG，用户手动提交。

本次不依赖 GPU、不训练网络、不自动调参。若身份/检测没有稳定净收益，不提升默认；不能因局部 MAE 改善而忽略身份退化。

## 兼容性、结论与 Git

原版、原版+恢复的八条序列输出 SHA-256 和全部 1m 指标字典均与 `identity_recovery_full_20261023.json` 完全相同。两组原/恢复组合的非 ID 证据指纹逐序列相同；困难单跑与全量对应行相同。验证全部 sample ID 相邻差为 1，GT 只作离线评估。新增的噪声文件参数在验证前冻结、两次完整回放不变。

结果不支持用此状态估计替换默认关联；实现保留为显式失败对照，不更改默认模型或训练。停止这一轮参数/规则扩展。历史预测、特征距离、优先级和生命周期修改已多次出现局部改善而身份退化，下一项应直接检验**近邻竞争候选的短窗关联是否可学习、是否具备足够可分辨信息**，先以固定样本的关联判别检验，再决定如何接回跟踪；不能保证新学习头必然解决交叉。
